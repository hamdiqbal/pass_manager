Firebase integration notes

What I changed
- Added `firebase_core`, `firebase_analytics`, and `firebase_crashlytics` to `pubspec.yaml` and ran `flutter pub get`.
- Initialized Firebase in `lib/main.dart` using the generated `lib/firebase_options.dart`.
- `android/settings.gradle.kts` already declares the `com.google.gms.google-services` plugin and `android/app/build.gradle.kts` applies the plugin.

Quick verification steps

1) Ensure Android config file exists
- Confirm `android/app/google-services.json` is present. This repo's `firebase.json` suggests it was generated by FlutterFire CLI and points to `android/app/google-services.json` as the file output.

2) Check iOS
- If you target iOS, ensure `ios/Runner/GoogleService-Info.plist` is present.

3) Run dependencies

```bash
flutter pub get
flutter analyze
```

4) Run the app

```bash
# Android
flutter run -d android

# iOS (macOS host)
flutter run -d ios
```

Notes and next steps
- If you need additional Firebase services (Auth, Firestore, Storage), add their packages to `pubspec.yaml` and follow setup steps for Android/iOS.
- If you run into Gradle plugin version mismatches, open `android/settings.gradle.kts` and update the `com.google.gms.google-services` version.
- For web support, run the FlutterFire CLI to regenerate `lib/firebase_options.dart` with web configs.
